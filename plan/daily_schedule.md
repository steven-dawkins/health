# Day-by-day schedule: MK Marathon, Monday 3 May 2027

Generated by `build_schedule.py` from the weekly structure in `marathon_plan.md`. Read that file first for the strategy, decision gates and safeguards. Distances are total run km for the day including warm-up and cool-down.

**Conventions.** Easy = 5:30-6:00/km, HR under ~140. Steady 5:10-5:20. MP is a provisional 5:00/km until Gate 2 (Sun 28 Mar 2027) sets the final figure. Threshold 4:30-4:35, 10k ~4:25, 5k 4:10-4:15. Quality sessions start with ~2 km easy and finish with ~2 km easy. **Strength** (30 min: single-leg squats, step-ups, calf raises, hip stability) goes after the run on Wed and Fri, or on its own if the day is a rest run day.

**Recovery rule.** If resting HR is 4+ bpm above ~47 for 3 days, or 7-day HRV is below ~50 ms, swap that week's Tuesday or Thursday session for easy running. Skip a hard session before skipping a down week. Any niggle over 3 days: cut quality first, then the long run.

**Christmas.** Fri 25 Dec and Sat 26 Dec are in week 7. Run them as scheduled (Friday easy, Saturday easy or a controlled Boxing Day parkrun if one is on).
